An entry for make.fun's ["The Word You'd Delete From the Dictionary"](https://make.fun/bounty/u-puan-the-word-you-d-delete-from-the-dictionary-9e774bc2) bounty.

The program scores six candidate words on the judge's own criteria — how fast the joke lands, how much humour comes from the word itself, and how fresh the pick is — then writes the single winning word to `/output/entry.txt`.

The winning word is **onomatopoeia**: the word about sounds is itself unspellable, so deleting it is a mercy the whole dictionary can get behind.

Run it with Node 22:

```sh
node main.ts
```

It writes exactly one word, `onomatopoeia`, to `/output/entry.txt`.
